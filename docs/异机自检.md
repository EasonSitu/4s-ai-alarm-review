# 4S 接入操作

4S 先用 `GET /healthz` 检查服务，再向 `POST /api/v1/tasks` 提交报警图片。所有项目使用同一套复核流程。

需要命令行提交时，在接入包的解压目录运行以下命令，将地址、项目编号、报警编号和图片路径替换成实际值。检查反光衣时把 `no_helmet` 改为 `no_vest`。

```sh
python3 scripts/submit.py "图片路径.jpg" --base "<BASE_URL>/api/v1" --project "<项目编号>" --alert "<报警编号>" --type no_helmet --wait
```

提示时输入 4S 接口令牌。服务先返回任务号，审核完成后输出结论。图片会发送给当前配置的模型供应商。
